This contribution presents calculated properties of 23 two-dimensional altermagnetic candidates from a symmetry-guided screening of the Materials Cloud 2D Crystals database. The study combines magnetic-symmetry analysis with DFT+U calculations and first-principles, self-consistent Hubbard parameters obtained using density-functional perturbation theory. The data include Hubbard U values, maximum spin splittings across the two-dimensional Brillouin zone and for states near the Fermi level, electronic band gaps, magnetic energy differences, discrete screened U values yielding altermagnetism, and workflow references. This contribution contains the complete set of 23 materials.
