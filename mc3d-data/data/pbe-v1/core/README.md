# The `mc3d/pbe-v1` base dataset

This dataset is based on the following AiiDA archive:

- `MC3D-provenance.aiida` in https://archive.materialscloud.org/record/2022.38

The base `mc3d/pbe-v1` data contains

- the optimized structures;
- a few calculated properties: energy, magnetization.

Note, run `hith/sourcedb_info_extras` before generating this data!
